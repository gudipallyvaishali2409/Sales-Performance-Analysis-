Project Overview

This project analyzes retail sales data using Python and Power BI to evaluate business performance and generate actionable insights. The dataset was cleaned, analyzed, and visualized to understand sales trends, customer segments, product categories, and regional performance.

The interactive Power BI dashboard helps stakeholders monitor key performance indicators (KPIs) and make data-driven business decisions.

Objectives :

Analyze overall sales performance.
Monitor key business metrics.
Compare sales across customer segments.
Evaluate product category performance.
Analyze regional sales distribution.
Study monthly sales trends.
Develop an interactive Power BI dashboard.
Dataset

Dataset Used: Sample Superstore Dataset

Python

Project Workflow:

1. Data Collection
Imported the Sample Superstore dataset into Jupyter Notebook.

2. Data Cleaning
Checked for missing values.
Removed duplicate records.
Corrected data types.
Prepared the dataset for analysis.

3. Exploratory Data Analysis (EDA)
Statistical summary
Sales analysis
Profit analysis
Category-wise analysis
Regional analysis
Monthly sales trend

4. Dashboard Development

Created an interactive Power BI dashboard with KPI cards, charts, and slicers.
